# Лабораторная работа

## Тема

Fine-tuning нейронной сети для краткосрочного прогноза глюкозы на ограниченном
персональном наборе данных.

## Цель

Исследовать, улучшает ли предварительное обучение на синтетической популяции
SimGlucose качество прогноза после адаптации на небольшом персональном наборе.

## Постановка задачи

По 60 минутам истории предсказывается CGM через 30 минут. Вход содержит только
наблюдаемые исторические данные: CGM, недавние углеводы, зафиксированные события
инсулина и время суток. Выход модели — изменение глюкозы относительно последней
точки. Модель не рассчитывает дозу и не является медицинским изделием.

## Данные

- SimGlucose: 6 виртуальных пациентов по 3 суток.
- Персональный экспорт: 6915 CGM-точек после фильтрации.
- Принятые приёмы пищи: 471.
- События инсулина: 347.
- Исключённые sensor sessions: 1.
- Персональные окна train/validation/test: 4113/1353/1353.
- Для fine-tuning использовано 1028 окон, 25% personal train.

Разбиение выполняется хронологически. Между частями оставлен purge gap длиной
90 минут, поэтому перекрывающиеся окна на границе не создают утечку.
Corrupted sensor intervals исключаются по флагу экспорта.

## Архитектура

Однослойная GRU с 32 скрытыми признаками, LayerNorm и двухслойной
регрессионной головой. Функция потерь — SmoothL1, оптимизатор — AdamW.
Количество входных признаков: 7.

## Эксперименты

| Метод | MAE, ммоль/л | RMSE, ммоль/л |
|---|---:|---:|
| persistence | 0.922 | 1.291 |
| scratch | 0.868 | 1.209 |
| pretrained | 0.954 | 1.351 |
| fine_tuned | **0.854** | **1.183** |

Fine-tuning снизил MAE относительно zero-shot pretrained модели на 10.4%, а
относительно persistence — на 7.3%. Fine-tuned модель также превзошла модель,
обученную с нуля на том же ограниченном personal subset.

## Вывод

Предварительное обучение на виртуальной популяции само по себе не переносится
на персональный ряд без domain adaptation: zero-shot pretrained модель уступила
даже persistence. После fine-tuning на 1028 персональных окнах она показала
лучшие MAE и RMSE среди сравниваемых методов. Это демонстрирует пользу переноса
обучения именно после персональной адаптации.

Результаты относятся только к исследованному временному диапазону и не
подтверждают клиническую пригодность модели.

## Ограничения

1. SimGlucose является математическим симулятором и не воспроизводит полностью
   конкретного человека.
2. В персональных данных возможны ошибки оценок углеводов и пропущенные события.
3. Использован один пользователь и один хронологический test interval.
4. Модель прогнозирует CGM, но не должна применяться для выбора лечения.
