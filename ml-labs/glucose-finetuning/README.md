# Лабораторная работа: fine-tuning модели прогноза глюкозы

Цель: показать перенос обучения с большой синтетической популяции на небольшой
персональный набор данных.

Модель решает исследовательскую задачу прогнозирования CGM через 30 минут по
последним 60 минутам наблюдений. Она не рассчитывает дозу инсулина и не должна
использоваться для лечебных решений.

## Схема эксперимента

1. SimGlucose генерирует временные ряды виртуальных пациентов.
2. Небольшая GRU обучается на синтетических рядах.
3. Экспорт Glucotracker читается напрямую из ZIP:
   - исключаются sensor sessions с `excluded_from_analytics=true`;
   - приёмы пищи переводятся из локального времени `Europe/Samara` в UTC;
   - CGM приводится к сетке 5 минут;
   - короткие пропуски до 10 минут интерполируются, длинные разрывы сохраняются.
4. Персональные окна делятся хронологически: train / validation / test.
5. Для fine-tuning используется только ограниченная часть personal train.
6. Сравниваются:
   - persistence: прогноз равен последнему CGM;
   - scratch: GRU обучена только на малом персональном наборе;
   - pretrained: синтетическая модель без адаптации;
   - fine-tuned: та же модель после персонального дообучения.

## Запуск

```powershell
cd ml-labs\glucose-finetuning
python run_experiment.py `
  --export-zip "C:\path\to\glucotracker-export.zip"
```

Быстрая проверка с меньшим объёмом симуляции:

```powershell
python run_experiment.py --export-zip "C:\path\to\export.zip" --quick
```

Результаты записываются в `results/`:

- `metrics.json` — метрики и размеры выборок;
- `comparison.png` — сравнение MAE/RMSE;
- `training_curves.png` — кривые обучения;
- `LAB_REPORT.md` — заполненный отчёт.

Персональные строки, фотографии, названия еды и идентификаторы не записываются.
Заполненная версия отчёта последнего проверенного прогона также находится в
корневом файле `LAB_REPORT.md`.

Для демонстрации в Jupyter можно открыть `lab_notebook.ipynb`, указать путь к
экспорту в первой кодовой ячейке и выполнить ячейки по порядку.

## Эксперимент по пищевым эпизодам

Отдельный эксперимент использует `meal_insulin_episode_snapshots` и прогнозирует
фактическую глюкозу `+2h` по данным, известным до/во время эпизода:

```powershell
python episode_experiment.py `
  --export-zip "C:\path\to\glucotracker-export.zip"
```

Он создаёт:

- `EPISODE_REPORT.md` — подробное объяснение эксперимента;
- `results/episode_comparison_ru.png` — сравнение ошибок с русскими подписями;
- `results/episode_predictions_ru.png` — прогнозы на поздних test-эпизодах;
- `results/episode_metrics.json` — полные численные результаты.
